# Alarm Clock

A console-based alarm clock application written in Java. The program allows the user to set an alarm time, displays the current time every second, and plays a custom alarm sound when the specified time is reached.

## Features

- Set a custom alarm time
- Live digital clock
- Input validation
- Plays a WAV alarm sound
- Multi-threaded execution
- Console interface

## Java Concepts Used

- Classes & Objects
- Constructors
- Methods
- Threads (`Runnable`)
- LocalTime
- DateTimeFormatter
- Exception Handling (`try/catch`)
- Scanner
- File Handling
- Audio Playback (`Clip API`)
